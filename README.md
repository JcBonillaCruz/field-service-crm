# Field Service CRM

CRM SaaS profesional para compañías de servicios en campo (HVAC, limpieza, restauración).

## Funcionalidades Planificadas

- **Multi-Compañía:** Un dueño puede manejar múltiples empresas independientes
- **Clientes y Direcciones:** Gestión de clientes con múltiples ubicaciones de servicio
- **Cotizaciones y Contratos:** Con firma digital táctil desde el celular
- **Facturación PDF:** Generación automática de facturas profesionales
- **Inventario por Camioneta:** Control de piezas por técnico/vehículo con alertas de resurtido
- **Calendario de Despacho:** Asignación visual de trabajos a técnicos
- **GPS y Cronómetro:** Seguimiento en tiempo real de técnicos en campo
- **App Instalable (PWA):** Funciona como app nativa en celular, tablet y computadora

## Stack Tecnológico

- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS
- **Base de Datos:** Supabase (PostgreSQL + Auth + Storage)
- **Hosting:** Vercel
- **Pagos:** Stripe (futuro)
